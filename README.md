# แผนที่กีฬา ลาดกระบัง

หน้าเว็บแผนที่แสดงสนามกีฬา ยิม และบริการเสริมรอบที่ดิน 14 ไร่ (ลาดกระบัง กรุงเทพฯ)
ใช้ Leaflet กับภาพดาวเทียม Esri World Imagery โหลดสดจากเบราว์เซอร์ ไม่ต้องใช้ API key

มีไฟล์เดียวคือ `index.html` (ข้อมูลสถานที่ 144 แห่งและขอบเขตที่ดินฝังอยู่ในไฟล์)

## เผยแพร่

**Netlify:** เข้า https://app.netlify.com/drop แล้วลากโฟลเดอร์นี้ใส่ได้เลย หรือเปิดเว็บเดิมของคุณ แล้วอัปโหลด `index.html` ทับ
**GitHub Pages:** อัปโหลด `index.html` ขึ้น repository แล้วไป Settings > Pages > Deploy from a branch > `main` / `(root)`

ต้องเปิดผ่านเว็บ (http/https) ถ้าดับเบิลคลิกเปิดไฟล์จากเครื่องตรงๆ ภาพแผนที่และการค้นหาอาจไม่ทำงาน

## สิ่งที่มี

- ภาพดาวเทียม + ชื่อสถานที่, ดาวเทียมล้วน, แผนที่ถนน (OpenStreetMap)
- ขอบเขตที่ดินจากพิกัด 4 มุม และวงรัศมี 3/5/10/15/20 กม.
- กรองตามกีฬา ประเภทสถานที่ การคิดเงิน ระยะทาง เปลี่ยนสีหมุด และขนาดตามรีวิว
- ค้นหาสถานที่ทั่วไทยหรือใส่พิกัด แล้ววางหมุดวัดระยะจากที่ดิน
- ปุ่มวางหมุดวัดระยะบนแผนที่ และลิงก์เปิดใน Google Maps

## ข้อควรระวัง

- ช่องค้นหาใช้ Nominatim ของ OpenStreetMap ชื่อร้านบางแห่งอาจไม่ครบเท่า Google Maps และมีข้อกำหนดให้ใช้อย่างเหมาะสม ไม่ยิงถี่ ถ้าใช้จริงจังหลายคนพร้อมกัน ควรเปลี่ยนไปใช้บริการค้นหาที่มีคีย์ของตัวเอง
- ภาพดาวเทียม Esri เป็นภาพ ณ วันที่ถ่าย ไม่ใช่ปัจจุบัน และต้องแสดงเครดิตมุมล่างขวาไว้ตามเดิม
- ประเภทสถานที่และกีฬาที่รองรับจัดจากชื่อและคำอธิบาย ไม่ได้ตรวจทีละแห่ง ระยะทางเป็นเส้นตรงจากที่ดิน
